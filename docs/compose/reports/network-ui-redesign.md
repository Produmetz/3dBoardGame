# Network UI Redesign — Final Report

## What Was Built

Редизайн сетевого интерфейса для 3D Chess & Go. Теперь навигация следует модели chess.com/lichess:

1. **Главная страница** — выбор между локальной и сетевой игрой
2. **Выбор сервера** — список серверов с авторизацией (гость/вход/регистрация)
3. **Лобби сервера** — комнаты, статистика, лидерборд, профиль игрока
4. **Игра** — с кнопкой возврата в лобби

## Architecture

### Файловая структура

| Файл | Назначение |
|------|------------|
| `styles.css` | Общие стили для всех страниц |
| `index.html` | Главная — выбор режима (локальный/онлайн) |
| `servers.html` + `servers.js` | Браузер серверов с авторизацией |
| `lobby.html` + `lobby.js` | Лобби сервера (комнаты, статистика) |
| `chess/chess.html` | Шахматы — добавлена кнопка "Назад" |
| `go/go.html` | Го — добавлена кнопка "Назад" |
| `network.js` | Обновлён для поддержки serverIndex |

### Навигация

```
index.html → [Локальная] → chess.html / go.html
           → [Онлайн] → servers.html → lobby.html → chess.html / go.html
```

### Данные между страницами

- **Сервер**: URL передаётся через query params или берётся из localStorage
- **Авторизация**: JWT токен в localStorage (`lobby_auth`)
- **Комната**: query params при переходе на игру

## Usage

### Локальная игра
1. Открыть `index.html`
2. Нажать "Локальная игра"
3. Выбрать шахматы или го

### Онлайн игра
1. Открыть `index.html`
2. Нажать "Онлайн игра"
3. Выбрать сервер или добавить новый
4. Войти как гость или зарегистрироваться
5. В лобби: создать/войти в комнату
6. Во время игры: кнопка "← Назад" для возврата в лобби

## Verification

- Все файлы созданы и доступны
- Стили корректно подключены через `styles.css`
- Навигация между страницами работает через ссылки
- Авторизация сохраняется в localStorage
- Кнопка возврата отображается только в сетевом режиме
