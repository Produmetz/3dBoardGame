# Дизайн-спека: Редизайн сетевого интерфейса

> [!NOTE]
> This document may not reflect the current implementation.
> See the final report for up-to-date state:
> [Final Report](../reports/network-ui-redesign.md)

## [S1] Проблема
Текущий интерфейс неудобен для навигации между локальной и сетевой игрой. Нет четкого разделения между выбором сервера, лобби и игрой. Пользователю сложно понять, где он находится и как вернуться назад.

## [S2] Решение
Многостраничная архитектура с четким флоу:

```
index.html → [Локальная игра] → chess.html / go.html
           → [Онлайн] → servers.html → lobby.html → chess.html / go.html
```

## [S3] Страницы

### index.html — Главная
- Два основных блока: "Локальная игра" и "Онлайн"
- Локальная: выбор шахмат/го → прямой переход на игровую страницу
- Онлайн: переход на servers.html

### servers.html — Выбор сервера
- Список серверов с карточками:
  - Название, URL, статус (онлайн/офлайн)
  - Статистика: игроки онлайн, количество комнат
  - Краткое описание
- Кнопки: "Подключиться", "Добавить сервер"
- Форма авторизации: гость, вход, регистрация
- После авторизации → lobby.html?server=...

### lobby.html — Лобби сервера
- Шапка: название сервера, кнопки "Сменить сервер", "Выйти"
- Левая колонка: список комнат с фильтрами, создание комнат
- Правая колонка: профиль игрока, статистика, лидерборд, история игр
- Вход в комнату → chess.html / go.html

### chess.html / go.html — Игра
- Кнопка "Назад в лобби" в шапке
- Существующий функционал игры

## [S4] Переходы

| Откуда | Куда | Условие |
|--------|------|---------|
| index.html | chess.html / go.html | Локальная игра |
| index.html | servers.html | Онлайн |
| servers.html | lobby.html | Авторизация успешна |
| lobby.html | chess.html / go.html | Вход в комнату |
| lobby.html | servers.html | Смена сервера / выход |
| chess.html / go.html | lobby.html | Кнопка "Назад" |

## [S5] Данные между страницами
- Сервер: URL передается через query params
- Авторизация: JWT токен в localStorage
- Информация о комнате: query params при переходе на игру

## [S6] Стили
- Единый CSS для всех страниц (общий файл styles.css)
- Текущий дизайн保持 (темная тема, accent цвет #4cc9f0)
- Адаптивность для мобильных устройств

## [S7] Порядок реализации
1. Создать общие стили (styles.css)
2. Обновить index.html (главная с выбором режима)
3. Создать servers.html (выбор сервера)
4. Обновить lobby.html (лобби с навигацией)
5. Обновить chess.html / go.html (кнопка "Назад")
6. Обновить network.js и lobby.js под новую структуру
