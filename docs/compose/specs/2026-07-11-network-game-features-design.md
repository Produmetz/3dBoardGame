# Сетевые фичи: ничья, сдача, результат, реванш, рейтинг, профиль

## [S1] Три типа игр

| Тип | Рейтинг | Статистика | Сохранение |
|-----|---------|------------|------------|
| Rated | Да | Да | Да |
| Unranked | Нет | Да | Да |
| Casual | Нет | Нет | Нет |

При создании комнаты в лобби — выпадающий список с этими тремя вариантами. По умолчанию Rated.

На сервере в `Room` добавить поле `game_mode` (`rated`/`unranked`/`casual`). Передавать клиенту в `room_created` и `joined_room`.

## [S2] Исправление ничьей

**Сейчас:** `offer-draw` показывает alert "не реализовано".

**Должно:**
1. Клиент отправляет `{type: 'draw_offer'}` на сервер
2. Сервер пересылает `{type: 'draw_offer', from: playerName}` оппоненту
3. Оппонент получает модальное окно "Противник предлагает ничью. принять?"
4. Ответ: `{type: 'draw_response', accepted: true/false}`
5. Сервер пересылает ответ инициатору
6. Если принято — оба получают `{type: 'game_over', result: 'draw'}`

**Файлы:** `network.js`, `server.py`, `chess/event-handlers.js`, `chess/game.js`

## [S3] Исправление сдачи

**Сейчас:** `resign-btn` скрывает панель.

**Должно:**
1. Клиент отправляет `{type: 'resign'}` (уже работает)
2. Сервер обрабатывает: фиксирует результат, отправляет `{type: 'game_over', winner: opponentName, result: 'resign'}` обоим игрокам
3. Клиент показывает панель результата вместо скрытия

**Файлы:** `server.py`, `chess/game.js`

## [S4] Панель результата игры

При завершении игры (мат, ничья, сдача) показывать в правой панели:

```
╔══════════════════════════╗
║     ИГРА ОКОНЧЕНА        ║
║                          ║
║  Результат: Победа белых ║
║  Причина: Мат            ║
║                          ║
║  [Реванш]  [В лобби]    ║
╚══════════════════════════╝
```

Элемент `#game-result-panel` в `chess.html`, скрыт по умолчанию. Показывается при `game_over`.

**Файлы:** `chess/chess.html`, `chess/game.js`, `chess/event-handlers.js`

## [S5] Реванш

1. Клиент отправляет `{type: 'rematch_offer'}`
2. Сервер пересылает оппоненту `{type: 'rematch_offer', from: playerName}`
3. Оппонент получает окно: "Противник предлагает реванш"
4. Ответ: `{type: 'rematch_response', accepted: true/false}`
5. Если принято — сервер перезапускает комнату, оба получают `{type: 'rematch_start', color: ...}` с новыми цветами (меняются местами)
6. Клиент сбрасывает доску и начинает новую игру

**Файлы:** `network.js`, `server.py`, `chess/game.js`
