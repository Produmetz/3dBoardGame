# Plan: Room flow improvements + spectators + color choice

## Problems
1. After creating room, immediately redirects to game — user wants to stay in lobby
2. No spectator support
3. No color choice settings

## Changes

### 1. lobby.js — Stay in lobby after creating room
- `onJoinedRoom()` should NOT redirect to game page
- Instead: show room in list with "Войти как игрок" / "Войти как зритель" buttons
- Keep WebSocket connection alive in lobby

### 2. lobby.html — Room card UI after creation
When you create or join a room, show it at top of room list:
```
Моя комната (создана вами)
[Войти как игрок] [Войти как зритель] [Удалить]
```

### 3. lobby.html — Join modal with role selection
When clicking a room, show modal with:
- Room name/info
- Password field (if needed)
- Role: Игрок / Зритель
- For chess: Color choice (if allowed by room settings)

### 4. server.py — Room settings
Add to Room class:
- `allow_spectators: bool` (default True)
- `color_mode: str` ('creator_pick' | 'free_choice', default 'creator_pick')

Add to create_room message:
- `allowSpectators`
- `colorMode`

Add to Room.to_dict():
- `allowSpectators`
- `colorMode`
- `ownerName`

### 5. server.py — Spectator support
- Add `spectators: list` to Room
- `join_room` with `role: 'spectator'` — adds to spectators list
- Spectators receive moves but can't make them
- Spectators count in room info

### 6. lobby.js — Join as spectator
- `joinRoom()` sends `role: 'spectator'` or `role: 'player'`
- Redirect to game with `role=spectator` param

### 7. network.js — Spectator mode
- If `role=spectator` in URL params, set `isSpectator = true`
- Spectators can't make moves, only watch
- Show "Вы зритель" in room info panel

### 8. lobby.html — Create room modal updates
Add fields:
- [x] Разрешить зрителей
- Цвет в шахматах: [Создатель выбирает / Свободный выбор]

## Files to modify
- `lobby.js` — stay in lobby, spectator join, room card UI
- `lobby.html` — create modal updates, join modal with role
- `server.py` — room settings, spectator support
- `network.js` — spectator mode
- `chess/game.js` — spectator mode (no moves)
- `go/game-go.js` — spectator mode (no moves)

## Verification
1. Create room → stay in lobby, see room in list
2. Click room → choose player/spectator
3. Join as spectator → can see game but can't move
4. Room settings: allow spectators, color mode
5. Two players can join and play
